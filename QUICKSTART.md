# 🚀 QUICK START - Aeroget

## ⚡ Installation en 3 Secondes!

### Windows
1. **Double-cliquez** sur `INSTALL.bat`
2. L'app se lance automatiquement! ✨

### macOS / Linux
1. **Double-cliquez** sur `INSTALL.sh` 
   - OU ouvrez Terminal et tapez: `bash INSTALL.sh`
2. L'app se lance automatiquement! ✨

---

## 📋 Pré-requis

- **Python 3.8+** (télécharger de [python.org](https://www.python.org))

Les scripts vérifieront automatiquement et vous afficheront un message d'erreur clair si Python n'est pas installé.

---

## ✅ Ce qui se passe quand vous lancez

1. ✓ Vérifie que Python est installé
2. ✓ Crée un environnement virtuel (première fois uniquement)
3. ✓ Installe automatiquement toutes les dépendances
4. ✓ Lance Aeroget dans toute sa splendeur Frutiger Aero! 🎨

## 🆘 Ça ne marche pas?

### Erreur: "Python not found"
- Installez Python depuis [python.org](https://www.python.org)
- **IMPORTANT**: Cochez "Add Python to PATH" lors de l'installation
- Redémarrez votre ordinateur après l'installation

### Erreur: "Permission denied" (macOS/Linux)
- Ouvrez Terminal
- Tapez: `chmod +x INSTALL.sh`
- Relancez: `bash INSTALL.sh`

### Erreur sur PyQt6
```bash
# Sur Linux (Ubuntu/Debian):
sudo apt-get install python3-pyqt6

# Sur macOS:
brew install pyqt6
```

### Autre problème?
1. Consultez `INSTALLATION.md` pour le guide complet
2. Consultez `ADVANCED.md` pour les solutions avancées
3. Ouvrez une issue sur GitHub
