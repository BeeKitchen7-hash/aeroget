## ⚡ Installation Super Rapide (3 étapes)

### **Étape 1: Télécharger le projet**

#### Option A: Avec Git (Recommandé)
```bash
git clone https://github.com/BeeKitchen7-hash/aeroget.git
cd aeroget
```

#### Option B: Télécharger le ZIP
1. Allez sur https://github.com/BeeKitchen7-hash/aeroget
2. Cliquez "Code" > "Download ZIP"
3. Extrayez le ZIP
4. Ouvrez le dossier

---

### **Étape 2: Exécuter le script d'installation**

#### Windows
1. Naviguez vers le dossier `aeroget`
2. **Double-cliquez** sur `INSTALL.bat`
3. Attendez que ça se termine... ✨

#### macOS / Linux
1. Naviguez vers le dossier `aeroget`
2. **Double-cliquez** sur `INSTALL.sh` 
   - OU ouvrez Terminal et tapez: `bash INSTALL.sh`
3. Attendez que ça se termine... ✨

---

### **Étape 3: C'est fini! 🎉**

L'application Aeroget se lance automatiquement!

## 🆘 Dépannage

### "Python not found"
- Installez Python depuis [python.org](https://www.python.org)
- ⚠️ **IMPORTANT**: Cochez "Add Python to PATH" lors de l'installation
- Redémarrez votre ordinateur

### "Permission denied" (macOS/Linux)
```bash
chmod +x INSTALL.sh
bash INSTALL.sh
```

### "pip: command not found"
Python n'est pas correctement installé. Réinstallez depuis [python.org](https://www.python.org)

### Autre problème?
Consultez `INSTALLATION.md` pour des solutions détaillées.

## 📚 Après l'Installation

### Lancer manuellement (sans script)
```bash
cd aeroget
# Activation environnement virtuel:
# Windows:
venv\Scripts\activate

# macOS/Linux:
source venv/bin/activate

# Lancer l'app:
python run.py
```

### Utiliser la CLI
```bash
python cli.py --interactive
```
